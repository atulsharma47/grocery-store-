# 🛒 Grocery Store Website

A simple and responsive grocery store website built using **HTML, CSS, and JavaScript**.  
This project showcases a clean grocery shopping interface with a modern UI and responsive design.

---

## 🚀 Live Demo

🔗 https://idyllic-sfogliatella-9d2118.netlify.app/

---

## 📌 Features

- Responsive grocery store homepage
- Clean and simple user interface
- Product display sections
- Built using pure HTML, CSS, and JavaScript
- Beginner-friendly frontend project

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💻 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/atulsharma47/grocery-store-.git
```

### 2. Open the project folder

```bash
cd grocery-store-
```

### 3. Run the project

Simply open `index.html` in your browser.
